What I've built

Selected Projects

01 — Capstone
AgriSense

Handheld multi-modal soil diagnostic device for smallholder farmers. Uses BIS and electrochemical sensing to measure pH, NPK, temperature, and soil moisture in the field.

ESP32 AD5933 LoRa C/C++ Atlas Scientific
GitHub Demo
02 — Embedded Systems
Smart Classroom Automation

ATmega328P-based classroom automation system using dual PIR sensors, a 3-channel relay for lighting/AC control, and an I2C LCD — migrated from breadboard to PCB for signal stability.

ATmega328P HC-SR501 I2C LCD Arduino PCB Design
GitHub Report
03 — Bioinstrumentation
Wearable SCD Monitor

ESP32-based wearable for sickle cell disease crisis detection. Fuses MAX30102 (SpO2/HR), TMP117 (temperature), and MPU-6050 (motion) with a Python ML classification pipeline.

ESP32 MAX30102 TMP117 Python ML
GitHub Slides
04 — Project Management
HBPRS — Hospital Biometric System

Hospital Biometric Patient Record System designed under LAPMAN LTD. Covers full project lifecycle — scope, risk matrix, EVM, communication plans, and stakeholder analysis.

System Design Risk Management EVM Biometrics
GitHub Deck
05 — Research
3D Printing Awareness Study

Survey-based research paper (N=68) on biomedical 3D printing awareness among healthcare professionals in Ghana. Used TAM framework, chi-square tests, and statistical analysis.

Research Statistics Python SciPy TAM
Paper Poster
06 — Embedded Systems
Automated Drug Delivery System

ESP32-controlled syringe pump for automated drug delivery. Integrates MAX30102, DS18B20, MPU6050, and a stepper motor with closed-loop dosing logic.

ESP32 Stepper Motor DS18B20 C/C++
GitHub Spec Doc
